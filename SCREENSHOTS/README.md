# Screenshots

This directory is reserved for screenshots of the project running in an SAP system.

## Important Note

- **No fake screenshots** are included in this project.
- Screenshots should only be added after the programs have been actually created and executed in an SAP ABAP development environment (e.g., SAP GUI / SAP BTP ABAP Environment).

## Suggested Screenshots to Add

Once you have access to an SAP system and have created/tested the programs, consider adding:

1. **SE11_ZPRODUCT.png** — ZPRODUCT table definition in SE11
2. **SE11_ZSUPPLIER.png** — ZSUPPLIER table definition in SE11
3. **SE11_ZSTOCK_MOVEMENT.png** — ZSTOCK_MOVEMENT table definition in SE11
4. **ZINVENTORY_REPORT_Selection.png** — Selection screen of the main report
5. **ZINVENTORY_REPORT_Output.png** — Output of the inventory report
6. **ZLOW_STOCK_REPORT_Output.png** — Low stock report output
7. **ZSTOCK_MOVEMENT_REPORT_Output.png** — Stock movement report output
8. **ZCATEGORY_REPORT_Output.png** — Category-wise report output
9. **ZINVENTORY_TEST_DATA_Output.png** — Test data insertion confirmation
10. **Debugger_Internal_Table.png** — Debugger showing internal table contents
11. **Debugger_Work_Area.png** — Debugger showing work area fields

## How to Take Screenshots in SAP GUI

1. Navigate to the desired screen (SE11, SE38, report output, etc.)
2. Press **Print Screen** or use the **Snipping Tool** (Windows)
3. Save as `.png` format
4. Add to this directory
5. Update the main README.md to reference the screenshots
